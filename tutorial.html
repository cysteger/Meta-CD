MBARC‑26 Validation Tutorial

This tutorial demonstrates how Meta‑CD was validated using the MBARC‑26 mock community, a defined mixture of 26 bacterial and archaeal genomes with known genome sizes, molarity, genome copy numbers, and sequencing representation (Singer et al., 2016). Because MBARC‑26 provides experimentally measured abundances and sequencing depth, it is an ideal benchmark for evaluating species‑specific coverage predictions.

1. Overview of the MBARC‑26 Dataset

MBARC‑26 consists of 26 genomes with published genome sizes (1.8–6.5 Mb), genome copy numbers, and Illumina read‑mapping abundances. The dataset includes a total sequencing depth of 155.8 Gb, enabling direct comparison between expected and observed coverage.

2. Selecting Parameters in Meta‑CD

For each organism, the following parameters were entered into Meta‑CD:

  • Genome size (Mb) from Singer et al. (2016)
  • Relative abundance (% mapped reads)
  • Total sequencing depth (155.8 Gb)
  • Optional DNA input quantity (ng) when evaluating DNA‑limited coverage

3. Expected Coverage from Meta‑CD

Meta‑CD calculates species‑specific coverage using:
C = (Deffective × 1000 × A) / G
where A is relative abundance, G is genome size, and Deffective accounts for DNA‑input constraints.

4. Comparison with Observed Coverage

The table below summarizes expected coverage from Meta‑CD and observed coverage reported in Singer et al. (2016). Coverage values match within rounding error, demonstrating that Meta‑CD accurately reproduces species‑specific coverage for a real metagenomic dataset.

5. Interpretation

The close agreement between expected and observed coverage confirms that Meta‑CD’s deterministic model accurately captures the relationship between sequencing depth, genome size, and relative abundance. This validation demonstrates that Meta‑CD can be used to evaluate species‑specific coverage in targeted or constrained metagenomic studies where abundances are known or experimentally controlled.
