About Meta‑CD

Meta‑CD is a biologist‑friendly calculator for species‑specific coverage estimation in metagenomic sequencing. It models how genome size, relative abundance, sequencing depth, and DNA quantity interact to determine whether a target species can be detected, profiled, or assembled. All computations run locally in the browser.

Frequently Asked Questions

  • Does Meta‑CD store user data? No — all calculations run locally in your browser.
  • Does Meta‑CD require installation? No — it runs entirely as a static web application.
  • Does DNA quantity always limit coverage? Only when sequencing depth exceeds the number of unique molecules in the sample.
  • Is Meta‑CD validated? Yes — validated using the MBARC‑26 mock community with known genome sizes and abundances.
